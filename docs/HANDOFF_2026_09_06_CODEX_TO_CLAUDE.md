## What is not finished

Do not tell Joe that every capability is complete merely because all four rooms render.

1. **The 2-GW comparison is not independently optimized.** It re-scores the same candidate
   squads generated by the six-week optimizer. The UI labels this `same candidate set`.
2. **Free-form what-if transfers are unscored.** They are visual, ephemeral scenarios and
   cannot be journaled until a real rebuild produces a scored plan.
3. **Model Form is mostly an honest empty state.** Once evidence exists, the current
   non-empty rendering is rudimentary; minutes error tables and charts still need work.
4. **Expert Room lacks the sharper expert-versus-model disagreement queue** and a complete
   creator matrix. It currently provides player grouping and a claim stream.
5. **Submitted-team confirmation is absent.** Public picks only prove the previous
   deadline's squad. Do not label a selected scenario as submitted.
6. **Working analysis snapshots are not retained.** Only current mutable caches and the
   immutable official archives exist; there is no rebuild-to-rebuild diff or flight recorder.
7. **Browser-level interaction coverage is absent.** Python, component and production-build
   checks passed, but there is no end-to-end browser test.
8. A native macOS `.app` is not built. The one-click `.command` launcher is the current
   low-friction entry point.
